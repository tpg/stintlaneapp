# StintLane

**See where your day actually went.**

StintLane is an automatic time tracker for macOS. It sits in your menu bar, notices which app you're in and what you're working on (the file, web page or folder), and sorts that time into projects using rules you write. Your activity data stays on your Mac.

- **Website:** [stintlane.app](https://stintlane.app)
- **Guide:** [stintlane.app/docs](https://stintlane.app/docs)

## What this repository is for

The StintLane source code isn't here. This repository is the public place to:

- **Report bugs.** Something isn't tracked correctly, a rule doesn't match, or the app crashes or misbehaves.
- **Request features.** Suggest improvements or new ideas.
- **Read the wiki** (if it's set up) for community notes and extra documentation.

For installation, setup and how-to questions, start with the [Guide](https://stintlane.app/docs).

## Reporting an issue

1. [Search existing issues](https://github.com/tpg/stintlaneapp/issues?q=is%3Aissue) first. Someone may already have reported the same thing. If so, add a 👍 or a comment with your details.
2. If not, [open a new issue](https://github.com/tpg/stintlaneapp/issues/new/choose) and pick the template that fits.
3. Include your StintLane version, macOS version and clear steps to reproduce. Screenshots help.

> [!IMPORTANT]
> Issues on this repository are **public**. StintLane records window titles, file paths and web addresses. Before you post screenshots, exports or logs, check them for names, client details or other private information, and blur or remove anything you don't want shared.
>
> Never post your license key.

## Requirements

- macOS 14 Sonoma or later
- Accessibility permission, which is optional but needed for window title, file and web address tracking

## Licensing and accounts

You need an account at [stintlane.app](https://stintlane.app) to get a trial key and to buy and manage licenses. Account and billing questions don't belong in public issues. Use your account at [stintlane.app](https://stintlane.app) for those.
